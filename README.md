# 🎬 MegaHype - Site Institucional

Bem-vindo ao repositório oficial do site da **MegaHype**, uma produtora audiovisual que transforma ideias em experiências visuais impactantes.

---

## 🚀 Sobre o MegaHype

A **MegaHype** é uma empresa de produção audiovisual especializada em:

- Produção de vídeos promocionais, institucionais e publicitários
- Edição profissional e pós-produção
- Soluções criativas para marcas e artistas


## 🛠️ Tecnologias Utilizadas

Este projeto utiliza:

- **Java** (backend)
- **HTML5, CSS3, JavaScript** (frontend)
- **Spring Boot**
